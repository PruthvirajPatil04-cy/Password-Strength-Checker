# 🔐 Password Strength Checker

A modern and responsive Password Strength Checker that helps users create stronger and more secure passwords. The application analyzes passwords in real time and provides instant feedback based on commonly used security criteria.

## ✨ Features

* Real-time password strength analysis
* Strength indicator (Weak, Medium, Strong)
* Checks password length
* Detects uppercase and lowercase letters
* Detects numbers
* Detects special characters
* Responsive and user-friendly interface
* Fast and lightweight
* Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 How to Use

1. Open the website in your browser.
2. Enter a password in the input field.
3. Instantly view the password strength and security feedback.
4. Improve your password based on the suggestions until it reaches a strong rating.
